# 🏎️ Formax Racing 方程式赛车队官方网站

华南理工大学 **Formax 方程式赛车队** 成立于 2009 年，是广东省第一辆 FSC 赛车的制造团队。车队每年自主设计制造两辆全新方程式赛车，分别参加中国大学生电动方程式大赛（电车）和无人驾驶方程式大赛（无人车）。

网站采用纯静态 **HTML + CSS + 原生 JavaScript** 构建，支持中英双语切换，已在 `scutracing.top` 域名下运行。
